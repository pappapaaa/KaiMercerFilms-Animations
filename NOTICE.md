# Code and reference provenance

The repository structure and generic `templates/audio/dsp.py` and `templates/audio/instruments.py` derive from [mromidev/claude-animated-shorts](https://github.com/mromidev/claude-animated-shorts), inspected at commit `e3b817b6afc6cd413466d43f11ba31209e034bbf`. Its MIT copyright notice is retained in `LICENSE`. The new animation modules, measurements, workflow and procedural courier assets were created for this project.

The four reference videos are identified in `references/sources.json`. Their creator is TheOdd1sOut. The downloaded videos, captions, screenshots, frame sheets and crops remain third-party material. They are local study evidence; this repository's code license does not license those media. The source hash and frame index are retained for attribution and reproducibility.

The example film uses an original courier, parcel room and synthesized Foley. No reference soundtrack, shot footage or traced source character is used in the proof render. The code package excludes reference imagery and downloads. The local study package includes the visual evidence requested for this study; it is not a clean public asset library.

Analytical claims distinguish measurements, observations and proposed implementation choices. The files do not claim access to the original creator's project files, rig, camera settings, shaders, voice stems or production software.
